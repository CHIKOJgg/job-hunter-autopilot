# 🚀 Job Hunter & Application Autopilot Service

Автономный сервис поиска вакансий, автоподачи откликов и мониторинга ответов HR для **Мирослава Писарика (Miraslau Pisaryk)**.

## Архитектура сервиса (24/7 в облаке Railway)

1. **Веб-дашборд и трекер (FastAPI + Uvicorn)**
   - Доступен из любого браузера 24/7 на порту `$PORT`
   - Интерактивный трекинг вакансий: фиксация кликов (`Посещено`), отметка статусов (`Отправлено`, `Интервью`, `Тестовое`, `Отказ`)
   - 1-клик скачивание всех 4 версий резюме (`Resume_RU.pdf`, `Resume_RU_1.pdf`, `Resume_EN.pdf`, `Resume_EN_1.pdf`)
   - 1-клик копирование персонализированного сопроводительного письма

2. **Фоновый демон автопоиска (Background Worker)**
   - Каждые 60 минут сканирует Хабр Карьеру, Remotive API, проверенные Telegram-каналы
   - Оценивает Match Score (соответствие стеку Java 21/25, Spring Boot 3/4, PostgreSQL, Redis, Docker)
   - Генерирует сопроводительные письма и автоматически синхронизирует базу данных SQLite и Excel

3. **Монитор входящих ответов от рекрутеров (IMAP Worker)**
   - Каждые 15 минут опрашивает входящие письма в Gmail
   - Анализирует ответы рекрутеров и классифицирует статусы (Интервью, Тестовое задание, Отказ)

## Локальный запуск через Docker

```bash
docker build -t job-hunter-service .
docker run -p 8080:8080 job-hunter-service
```
